# DB's Workouts: first website and fitness mini-tools

**My first website for DB's Workouts, a mobile personal training business in East London, together with a set of small fitness tools built in plain JavaScript while learning.**

---

## What's inside

| File | Description |
|---|---|
| `index.html` | Landing page: free consultation, PT services, sessions, bespoke workout plans, group training, and locations |
| `fitness tracker.html` | **FitTrack**, a fitness goal and workout tracker |
| `food tracker.html` | A simple food tracker |
| `Nutrition log.html` | A nutrition tracker |
| `Grocery List Generator.html` | A grocery list and meal generator |
| `Game.html` | **Everyday Beast Mode**, the fitness game that became [Repping It](https://github.com/dean1234533/Repping-It) |

## Tech stack

HTML, CSS, and vanilla JavaScript. It has no frameworks and no build step.

## Run locally

```bash
git clone https://github.com/dean1234533/DB-s-Workouts.git
cd DB-s-Workouts
open index.html
```
